## Class templates

Function templates let one function work for many types. Class templates do the same for a whole class. A container, a wrapper, or a pair of values can be written once, with the type left open, and then used with any type. The standard library's containers are class templates: `std::vector<int>` and `std::vector<std::string>` come from one definition.

Here's the template from `src/main.cpp`:

```cpp
template <typename T>
class Box {
public:
    Box(T value) {
        item = value;
    }

    T get() const {
        return item;
    }

    void set(T value) {
        item = value;
    }

private:
    T item;
};
```

The `template <typename T>` line applies to the whole class, so `T` can appear in the members and the functions. Each use names the type in angle brackets:

```cpp
Box<int> number(42);
Box<std::string> word("hello");
```

`Box<int>` and `Box<std::string>` are separate classes, generated by the compiler from the same pattern. Each one has an `item` of its own type, and each one's functions take and return that type.

Press **Run**. The output is:

```
42
7
hello
```

The program creates a `Box<int>` holding 42, changes it to 7 with `set`, and reads the `Box<std::string>` holding "hello". The two boxes don't interfere with each other, since they're different types.

### Member functions

Member functions of a class template are written with the same `T` placeholder. Each member is generated only when the program uses it. A member that is never called may never be compiled for a given type, which is why an error inside an unused member may not show up until something calls it.

### Defining the template in a header

A class template usually lives in a header, for the same reason a function template does. Every file that uses `Box<int>` must see the whole class template to build its version, and that includes the member functions. So the whole definition goes in the header. This is the exception to the headers chapter's split. An ordinary class keeps its function bodies in a source file, but a template's bodies can't be moved there, since no other file could see them.

### Quiz

*These questions are written for this course.*

````quiz
How many classes does `Box<int>` and `Box<std::string>` produce?
○ One class, which holds either type.
→ Not quite. A template instance is a separate class for each type.
◉ Two classes, one generated for each type the template is used with.
→ Yes. Each instance is a separate class with its own member types.
○ None, since templates are never classes.
→ Not quite. A template is a pattern for classes, and each instance is a real class.
````

````quiz
Why is a class template's definition usually in a header?
○ Because classes can only be defined in headers.
→ Not quite. Ordinary classes can be defined in a source file.
◉ Because every file that uses the template needs the whole definition to generate its own version.
→ Yes. The template can't be instantiated from a declaration alone.
○ Because headers are the only place where templates are allowed.
→ Not quite. Templates are allowed anywhere, but must be visible where they're used.
````
