## Solution: Introduce yourself

The example program prints three lines, one `std::cout` statement for each. Every line ends in `\n`, so each one starts on a new line.

The lines are separate statements, and each ends with a semicolon. You could join them into one long `cout` chain, and the output would be identical. Keeping them apart makes each line easy to change on its own.

The example uses placeholder text, so your version should say something about you. The requirements are the part that matters. Each line has to be there, in order, on its own line.
