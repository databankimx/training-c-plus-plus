## Final Project: A Calculator

This project brings the course together. Build a calculator that reads expressions and prints the results. Work in VS Code, in a project of your own, starting from an empty `main.cpp` in a folder with a `CMakeLists.txt` that builds an executable called `program`.

Start with the core, and add the bonus items when the core works. The full requirements are in the project overview. Each step below lists what it covers.

The two steps are:

1. **Core calculator.** Numbers, the four operators with precedence, parentheses, unary minus, clear errors, the REPL, and the `selftest` and `demo` modes.
2. **Bonus items.** Exponents with `^`, `sqrt(...)`, and square and curly brackets.

Reveal an example only when you're stuck. The example is a walkthrough of one possible design, and your version can differ, as long as it meets the requirements.
