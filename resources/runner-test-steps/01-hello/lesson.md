## Hello

This step is a program that prints one line. Press **Run** (or F5). The Output pane should show the build status lines, and then the program's text:

```
Hello, C++!
```

The Output pane ends with a line that says the run finished, with exit code 0.

---

### Try it in the runner

Change the text in `src/main.cpp`, and press **Run** again. The build status lines appear again, and the new text is printed. Press **Reset** to return the file to its saved version.
