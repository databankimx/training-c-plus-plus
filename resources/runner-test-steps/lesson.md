## Ch01 · Basics

This chapter is a short set of steps for checking the lesson runner. The programs are small, and each lesson says what to look for in the Output pane.

The steps are:

* [Hello](#goto/01-hello): a program that prints a line.
* [Input](#goto/02-input): a program that waits for you to type a line.
* [Tests](#goto/03-tests): a program with tests, which the Test button runs.

---

*These steps exist only to check the lesson runner. They aren't part of the course.*
