## Ch03 · Decisions

Up to now, every program has run from top to bottom, with each line happening once. This chapter lets a program choose. You'll work with the `bool` type, which holds true or false, combine conditions with logical operators, and use `if` to run different code depending on the values the program has.

The steps are:

* [Booleans and comparisons](#goto/01-booleans): the `bool` type, how it prints, and the operators that ask questions about values.
* [Logical operators](#goto/02-logical-operators): combining conditions with `&&`, `||`, and `!`, and how short-circuit evaluation works.
* [If statements](#goto/03-if-statements): `if`, `else`, `else if`, and the conditional operator.
* [Switch statements](#goto/04-switch): choosing between several cases for one value.
* [Summary](#goto/05-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
