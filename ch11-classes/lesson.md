## Ch11 · Classes

Structures group data, and this chapter adds behaviour. A class holds data together with the functions that work on it, and it controls which parts of the program can reach that data. You'll write classes with methods, constructors that set up each object, and private members that only change through checked functions.

The steps are:

* [Classes and objects](#goto/01-classes-and-objects): declaring a class, creating objects, and access labels.
* [Methods](#goto/02-methods): functions that belong to a class, `const` methods, and defining a method outside its class.
* [Constructors](#goto/03-constructors): setting up an object when it's created, and how brace initialization changes.
* [Access and encapsulation](#goto/04-encapsulation): private data, getters and setters, and checks that protect an object's rules.
* [Summary](#goto/05-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
