## Ch07 · Functions

Up to now, every program has been one `main` function. This chapter splits a program into named functions, so each piece has a job, and the same job can be used from several places. You'll learn how to define and declare a function, how values go in through parameters and come out through return values, how arrays are passed, how a function can change its caller's variables, and how a function can call itself.

The steps are:

* [Defining functions](#goto/01-defining-functions): defining and calling a function, and declaring it before use.
* [Parameters](#goto/02-parameters): passing arguments, and default values.
* [Return values and overloading](#goto/03-return-values): sending a result back, and giving one name to several functions.
* [Arrays as parameters](#goto/04-arrays-as-parameters): passing an array, and why its size has to be passed too.
* [Reference parameters](#goto/05-reference-parameters): letting a function change its caller's variables.
* [Recursion](#goto/06-recursion): a function that calls itself, traversing a folder tree.
* [Summary](#goto/07-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
